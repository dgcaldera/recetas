# Albóndigas en Caldillo de Jitomate

**Porciones:** 3  
**Tiempo:** ~45 min  
**Dificultad:** Media  
**Proteína:** Res  
**Día ideal:** Martes o Jueves (entre semana)

---

## Ingredientes

| Cantidad | Ingrediente |
|----------|-------------|
| 400g | Carne molida de res |
| 1 | Huevo |
| 3 cdas | Pan molido |
| ½ cdita | Ajo en polvo |
| ½ cdita | Comino molido |
| 1 cdita | Sal para las albóndigas |
| ½ cdita | Pimienta negra |
| 3 | Jitomates medianos *(o 1 lata 400g)* |
| ½ | Cebolla mediana |
| 2 | Dientes de ajo |
| 500ml | Caldo de res |
| 2 | Papas medianas, en cubos |
| 2 | Zanahorias medianas, en cubos |
| 2 cdas | Aceite vegetal |
| ½ cdita | Orégano seco |
| 1 cdita | Sal para el caldillo |
| 2 cdas | Cilantro fresco picado (para servir) |

---

## Pasos

1. **Preparar las albóndigas** — En un tazón mezcla la carne molida, el huevo, el pan molido, el ajo en polvo, el comino, la sal y la pimienta. Mezcla bien con las manos hasta obtener una mezcla homogénea. Forma bolitas del tamaño de una nuez — no las aprietes demasiado. Reserva.

2. **Preparar la salsa de jitomate** — Licúa los jitomates, la cebolla y el ajo con ½ taza de agua hasta obtener una salsa homogénea. Reserva.

3. **Hacer el caldillo** — En una olla grande calienta el aceite a fuego medio-alto. Vierte la salsa de jitomate y sofríe ~5 min hasta que cambie de color y espese un poco. Agrega el caldo de res, el orégano y la sal. Lleva a hervor.

4. **Agregar verduras** — Agrega las papas y zanahorias en cubos al caldillo. Cocina ~5 min a fuego medio.

5. **Cocinar las albóndigas** — Agrega las albóndigas una por una con cuidado al caldillo hirviendo. No las muevas los primeros 10 min — deja que se cocinen y asienten. Luego mueve suavemente. Cocina a fuego medio-bajo ~20 min hasta que las albóndigas estén bien cocidas y las verduras tiernas. Prueba y ajusta sal.

6. **Servir** — Sirve las albóndigas con su caldillo en tazón profundo. Espolvorea cilantro fresco encima. Acompaña con arroz blanco o tortillas de maíz calientes.

---

## Notas

- 🥩 **No aprietes las albóndigas:** Forma las bolitas suavemente — si las aprietas mucho quedan duras. Solo lo suficiente para que se peguen.
- ⏱️ **No muevas las albóndigas al principio:** Una vez que las agregas al caldillo, no las toques los primeros 10 min — si las mueves se deshacen.
- 🌿 **Tip de sabor:** Puedes agregar un trozo pequeño de menta o yerbabuena a las albóndigas — es el secreto de muchas recetas mexicanas para darles frescura.
- 🍞 **Pan molido vs arroz:** Algunas recetas usan arroz crudo en lugar de pan molido para ligar las albóndigas — ambos funcionan bien.
